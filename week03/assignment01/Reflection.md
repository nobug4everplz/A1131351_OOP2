# 我的小房子 — Reflection

## 學到的概念

- Java 繪圖座標原點在左上角，y 向下增加；`fillRect(x, y, w, h)` 的 (x, y) 是左上角。
- 後畫的圖形會蓋住先畫的，所以順序是天空、草地、太陽、雲、房屋、屋頂、門窗、簽名。
- 用 `Math.cos`、`Math.sin` 搭配迴圈畫太陽光芒：每 30 度一條，12 條剛好一圈。
- 重複的圖形（窗戶）抽成方法 `drawWindow`，避免重複程式碼。

## 遇到的問題與解法

- 屋頂只能用三條 `drawLine`，所以不能用 `fillPolygon`，屋頂內部會是天空色，這是題目要求。
- 確認尺寸時發現視窗截圖是 500×428，多出來的 28 是標題列，畫布本身仍是 500×400。
- 簽名使用中文字，確認編譯時要加 `-encoding UTF-8`。

## 可改進之處

- 座標目前是寫死的數字，可以用變數（如房屋位置、大小）讓整體更容易調整。
- 可加入更多細節，例如煙囪、樹，或用 `Graphics2D` 調整線寬。
