# Week 01 Assignment 01 — AI 對話紀錄

本文件為重點整理，非逐字稿。紀錄起點為使用者宣告「以下開始是week 1 assignment 01 對話紀錄由此開始」，不包含先前骰子作業或 repo 整理對話。

## 使用者需求

使用者提供「作業_1.png」作為範例，題目要求使用 AI 生成「一個有輸入框和按鈕的登入視窗」，並檢視產生結果。AI 確認採 Java Swing、限定這份作業；使用者接著說「弄啊」，要求開始實作。

## AI 處理

1. 閱讀範例圖片及 repo 協作規則，界定只修改本作業與作業狀態索引。
2. 指出範例可見的空版面無元件座標、明文密碼框、字串使用 == 比較等問題；圖片被截斷部分不推測。
3. 產生 LoginWindow：帳號欄位、密碼欄位、登入按鈕及提示標籤。使用版面配置、EDT 與事件監聽器。
4. 僅示範輸入與按鈕回饋，不增加帳號驗證或資料庫。
5. 完成編譯、7 項基本功能斷言與三張真實執行截圖，並檢視畫面。
6. 整理規格、測試與原理說明，保留個人心得待填，提交獨立 PR 供使用者檢視。

實際證據見 [TESTING.md](TESTING.md)，設計說明見 [EXPLANATION.md](EXPLANATION.md)。本紀錄不代表使用者已理解、確認心得或同意合併。
